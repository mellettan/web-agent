# AI Web Agent

Это проект для создания автономного AI-агента, который управляет веб-браузером для выполнения задач, поставленных пользователем. Агент использует большую языковую модель (LLM), такую как GPT-4o-mini, для анализа содержимого веб-страниц и принятия решений о следующих действиях (переход по URL, ввод текста, клик).

Проект построен на принципах чистого, модульного и расширяемого кода (SOLID, DRY) для обеспечения надежности и простоты дальнейшей разработки.

## 🚀 Ключевые особенности

*   **Модульная архитектура**: Логика разделена на независимые компоненты (Агент, Браузер, LLM-клиент), что упрощает тестирование, модификацию и расширение.
*   **LLM-управляемое принятие решений**: Агент использует LLM для интерпретации состояния веб-страницы и выбора наиболее подходящего действия из предопределенного набора инструментов.
*   **Упрощенное представление DOM**: Специальный JavaScript-скрипт преобразует сложную веб-страницу в простое текстовое представление, содержащее только интерактивные элементы, что облегчает анализ для LLM.
*   **Централизованная конфигурация**: Все настройки (ключи API, имена моделей, тайм-ауты) управляются через `.env` файл и `config.py` с использованием Pydantic для валидации.
*   **Надежный цикл "Observe-Think-Act"**: Агент следует классическому циклу: получает состояние страницы, решает, что делать, выполняет действие и анализирует результат.
*   **Самокоррекция**: Встроенная логика для обработки неэффективных или неудачных действий, позволяющая агенту пересмотреть свою стратегию.

## 🏗️ Архитектура проекта

Проект имеет четкую структуру, где каждый файл выполняет свою единственную обязанность (Single Responsibility Principle).

*   **`main.py`**: Точка входа в приложение. Инициализирует все компоненты и запускает главного агента.
*   **`agent.py`**: "Мозг" проекта. Содержит класс `WebAgent`, который управляет основным циклом `Observe-Think-Act` (Наблюдение-Мысль-Действие), хранит историю сообщений и координирует взаимодействие между браузером и LLM.
*   **`browser_handler.py`**: "Руки" агента. Инкапсулирует всю логику взаимодействия с браузером (Playwright). Отвечает за навигацию, клики, ввод текста и извлечение содержимого страницы.
*   **`llm_client.py`**: "Коммуникатор". Отвечает за все взаимодействия с API OpenAI. Формирует запросы, отправляет их и обрабатывает ответы от LLM.
*   **`config.py`**: "Центр управления". Определяет все настройки приложения с помощью Pydantic, загружая их из переменных окружения и `.env` файла.
*   **`logging_setup.py`**: Настраивает систему логирования для вывода информации в консоль и файлы.
*   **`prompts.py`**: Хранит системный промпт, который определяет роль, правила и возможности AI-агента.
*   **`get_elements.js`**: JavaScript-файл, который выполняется в браузере для сканирования страницы и возвращения ее упрощенного текстового представления.

## ⚙️ Установка и запуск

### Требования

*   Python 3.10+
*   Poetry
*   Доступ к OpenAI API (или совместимому API)

### Шаги по установке

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <your-repository-url>
    cd <repository-folder>
    ```

2.  **Настройте `pyproject.toml`:**
    
    Убедитесь, что ваш `pyproject.toml` файл содержит все необходимые зависимости. Если вы начинаете с нуля, вот пример его содержимого:
    ```bash
    [project]
    name = "ai-agent"
    version = "0.1.0"
    description = ""
    authors = [
        {name = "yourname",email = "yourname@example.com"}
    ]
    readme = "README.md"
    requires-python = ">=3.11 <4.0"
    dependencies = [
        "openai (>=2.4.0,<3.0.0)",
        "python-dotenv (>=1.1.1,<2.0.0)",
        "loguru (>=0.7.3,<0.8.0)",
        "playwright (>=1.55.0,<2.0.0)",
        "tiktoken (>=0.12.0,<0.13.0)",
        "pydantic (>=2.12.2,<3.0.0)",
        "pydantic-settings (>=2.11.0,<3.0.0)",
        "black (>=25.9.0,<26.0.0)"
    ]
    
    
    [build-system]
    requires = ["poetry-core>=2.0.0,<3.0.0"]
    build-backend = "poetry.core.masonry.api"
    ```

3.  **Установите зависимости:**
    ```bash
    poetry install
    ```

4.  **Установите браузеры для Playwright:**
    
    (Этот шаг нужно выполнить только один раз)
    ```bash
    poetry run playwright install
    ```

5.  **Настройте переменные окружения:**
    
    Создайте файл `.env` в корневой директории проекта, скопировав содержимое из `.env.example` или создав его с нуля.

    **`.env` файл:**
    ```env
    # Обязательно: Ваш ключ от OpenAI API
    OPENAI_API_KEY="sk-..."

    # Необязательно: Если вы используете прокси или локальный LLM-сервер
    # OPENAI_BASE_URL="http://localhost:1234/v1"
    ```

### ▶️ Запуск агента

1.  Убедитесь, что ваше виртуальное окружение активировано.
2.  Запустите главный скрипт из корневой директории проекта:
    ```bash
    poetry run python main.py
    ```
3.  Следуйте инструкциям в консоли:
    *   Сначала программа попросит нажать `Enter`, чтобы передать управление агенту.
    *   Затем введите задачу, которую должен выполнить агент (например, "Зайди на сайт a.testaddressbook.com, войди в систему с почтой a@a.com и паролем a, затем выйди").
